# Personal Digital Profile — Starter

This is a responsive personal biodata/portfolio website populated from the supplied biodata image.

## Files
- index.html — page structure and placeholder content
- style.css — design and responsive layout
- script.js — personalization and starter visitor-counter notes

## Open it
Double-click index.html to preview it in a browser.

## Replace later
Update:
- name
- about text
- personal details
- education
- career
- hobbies
- email/social links
- the three photo placeholders

For real visitor tracking after the site is hosted, add an analytics service such as Google Analytics or Cloudflare Web Analytics. The included localStorage counter is only a demo and counts visits from the same browser.
